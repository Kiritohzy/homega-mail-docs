HOMEGA 邮件发送

从工作文件夹准备业务邮件和附件，使用经您授权的 Gmail 账号发送。

工作文件夹 → 本机发送工具 → Google Gmail → 指定收件人

这个工具做什么

HOMEGA 邮件发送是一款供 HOMEGA 授权成员使用的 Windows 工具。它根据既定业务流程准备主题、正文和文件附件，通过 Gmail API 提交邮件。日常入口是工作文件夹里的发送脚本。

为何需要 Google 授权

发送工具需要您的发信许可，以及用于核对登录账号的邮箱身份信息。它不要求读取收件箱或删除邮件的权限。首次配置时，您会在 Google 页面选择账号并授权；每台电脑分别配置。

使用前

由管理员完成应用配置后，使用者需确认收件人、邮件内容和附件。工具正在迁移配置阶段，公开说明页面并不表示两台电脑已经完成发送验收，也不提供公开注册或下载服务。

了解 隐私政策 和 使用条款。如需安装、授权撤销或故障协助，请联系页面下方的支持邮箱。

About this application

HOMEGA Mail is a Windows desktop utility for authorized HOMEGA team members. It prepares business emails and selected file attachments, verifies the signed-in email identity, and sends messages through the Gmail API after user authorization. This website is documentation only; it does not receive messages, attachments, or OAuth tokens.
